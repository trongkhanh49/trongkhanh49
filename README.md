## 🚀 Dự án nổi bật

## 🤖 [CheckStatsKingMC](https://github.com/trongkhanh49/CheckStatsKingMC)

> Discord Bot & Minecraft Bot system với kiến trúc Master–Worker, hỗ trợ quản lý nhiều Worker trên Render.

- 🟢 **Tech stack:** Node.js · Discord Bot · Minecraft Bot · REST API · Render
- 🤖 **Discord Bot:** Nhận và xử lý các lệnh `/stats`, `/bal`
- ⚙️ **Master–Worker:** Master Bot điều phối các Worker Bot thông qua API
- 🌐 **Multi-Worker:** Hỗ trợ triển khai nhiều Worker trên các Render Web Service
- 🎮 **Minecraft:** Worker duy trì Minecraft Bot và lấy dữ liệu từ server
- 📡 **API:** Master ↔ Worker giao tiếp thông qua HTTP API
- 🔄 **Queue System:** Hệ thống Queue Manager phân phối request đến Worker đang rảnh
- 🚨 **Monitoring:** Worker gửi thông báo disconnect/kick về Discord Admin
- ☁️ **Deployment:** Hỗ trợ triển khai Master và nhiều Worker trên Render
- 🔁 **Keep-Alive:** Có hệ thống Google Apps Script ping các service định kỳ

**Architecture:**

`Discord → Master Bot → Queue Manager → Worker Bot → Minecraft Server`

**Status:** 🟢 Active Development
